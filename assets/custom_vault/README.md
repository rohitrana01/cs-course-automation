# Custom Image Vault

Place your custom downloaded/created images here for each Day or Tech Fact.
The automated video pipeline will prioritize images placed in this folder over default assets.

## Supported Formats:
`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.bmp`, `.tiff`, `.gif`

## Naming Examples:
- Day 3: `day3_1.jpg`, `day3_2.png`, `day3_3.webp` (or folder `day3/`)
- Day 4: `day4_1.jpg`, `day4_2.jpg` (or folder `day4/`)
- Fact 1: `fact1_1.jpg`, `fact1_2.jpg` (or folder `fact1/`)
